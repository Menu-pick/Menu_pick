# 🍚 밥픽 (BapPick)

> **친구들과 밥 메뉴, 같이 정해요.**

**밥픽(BapPick)** 은 친구들과 함께 식사 메뉴를 결정하는 과정에서 발생하는 고민을 줄이고, 모두의 의견을 반영해 메뉴를 선택할 수 있도록 돕는 **그룹 기반 메뉴 추천 및 투표 웹 서비스**입니다.

사용자는 방을 생성하고 친구들을 초대하여 함께 메뉴를 정할 수 있습니다. 선택한 음식 카테고리를 바탕으로 메뉴 후보 3개를 추첨하고, 참여자들의 좋아요·싫어요 투표를 통해 최종 메뉴를 확정합니다.

매장 식사를 선택한 경우에는 확정된 메뉴와 기준 위치를 활용해 주변 식당을 추천받을 수 있으며, 선택한 식당은 캘린더에 기록되어 이후에도 확인할 수 있습니다. 또한 기존 방을 재사용할 수 있어 친구들과 새로운 식사를 정할 때마다 방을 다시 만들 필요가 없습니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
| --- | --- |
| **방 생성 및 친구 초대** | 식사 장소, 방식, 음식 카테고리를 설정하고 코드 또는 링크로 친구 초대 |
| **메뉴 후보 추첨** | 선택한 음식 카테고리를 기반으로 메뉴 후보 3개 추첨 |
| **메뉴 투표** | 참여자별 좋아요·싫어요 투표 및 실시간 결과 확인 |
| **최종 메뉴 확정** | 득표 결과를 바탕으로 최종 메뉴 선정 |
| **주변 식당 추천** | 확정 메뉴와 기준 위치를 활용한 주변 식당 추천 및 거리·도보 시간 제공 |
| **배달앱 연결** | 배달의민족·쿠팡이츠·요기요 웹사이트 연결 |
| **식당 기록 관리** | 최종 확정한 식당을 날짜별로 저장하고 캘린더에서 조회 |
| **기존 방 재사용** | 기존 방과 참여자를 유지하며 새로운 식사 선택 진행 |

---

## 🧭 서비스 이용 흐름

**STEP 1. 방 생성 및 친구 초대**

방 이름, 기준 장소, 식사 방식, 음식 카테고리를 설정하고 참여 코드 또는 초대 링크로 친구들을 초대합니다.

**STEP 2. 메뉴 후보 추첨**

선택한 음식 카테고리에서 메뉴 후보 3개를 무작위로 추첨합니다.

**STEP 3. 메뉴 투표 및 확정**

참여자들이 좋아요·싫어요 투표를 진행하고, 가장 많은 득표를 받은 메뉴를 최종 확정합니다.

**STEP 4. 식당 추천 또는 배달앱 연결**

- **매장:** 주변 식당 추천 → 식당 선택 → 최종 확정
- **배달:** 배달앱 선택 → 외부 웹사이트 이동 → 직접 주문

**STEP 5. 식당 기록 확인**

최종 확정한 식당은 방별 캘린더에 저장되며, 기존 방에서 새로운 식사 선택을 시작할 수 있습니다.
